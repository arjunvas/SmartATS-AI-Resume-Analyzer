# SmartATS-AI-Resume-Analyzer
AI-powered ATS Resume Analyzer using Python, NLP, Gemini API and Streamlit
SmartATS – AI-Powered Resume Analyzer

An AI-powered resume analysis application that evaluates a candidate's resume against a target job description. It extracts skills from PDF resumes, calculates skill matching percentages and TF-IDF text similarity, and generates AI-based feedback and improvement recommendations using Google's Gemini API. The application provides an interactive interface built with Streamlit.
